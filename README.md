# AgroMEDConnect

Connecting Bangladesh’s farmers with trusted agricultural and healthcare essentials. React + Vite + TypeScript.

## Run locally

```bash
# Go into the project folder after unzip
cd agromedconnect-new

# Install dependencies
npm install

# Start the site
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Language

Use the বাংলা / EN toggle in the top bar.

## Build

```bash
npm run build
npm run preview
```
